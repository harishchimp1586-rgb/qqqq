## 🏢 About Rejoice Enterprise

**Rejoice Enterprise** is committed to reducing single-use plastic waste by providing high-quality, nature-based disposable tableware. We serve homes, restaurants, catering services, corporate functions, events, and retail stores with durable, hygienic, and compostable alternatives.

### Core Values
- 🌱 **100% Eco-Friendly**: Biodegradable, plastic-free, and compostable materials.
- ⭐ **Superior Quality**: Sturdy, heat-resistant, leak-proof, and food-grade certified.
- 📦 **Comprehensive Variety**: Broad range of sizes, shapes, and utility products.
- 🤝 **Direct Support**: Quick wholesale quotations and customer support via direct call and WhatsApp.

## ✨ Key Features

- 📱 **Mobile-App Inspired UI**: App bar header, sticky bottom navigation bar, and clean touch-friendly card layouts.
- 🏷️ **Dynamic Category Filter**: Filter products across *Plates*, *Cups*, *Cutlery*, and *Trays*.
- 🛒 **Interactive Cart Counter**: Real-time visual feedback and item count badges for user interaction.
- ⚡ **Zero Dependencies**: Pure Vanilla HTML/CSS/JS for blazing-fast load times and lightweight footprint.
- 📞 **One-Tap Quick Contact**: Embedded direct call actions (`tel:6374450321`) and WhatsApp inquiry shortcuts.

## 🛠️ Tech Stack

- **Markup**: HTML5 (Semantic, accessible layout)

- **Scripting**: Vanilla JavaScript ES6+ (IntersectionObserver, DOM event listeners)

## 🚀 Quick Start & Local Preview

### Prerequisites
- Any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).

### Running Locally
1. Clone or download the repository:
   ```bash
   git clone https://github.com/harishchimp1586-rgb/qqqq.git
   cd qqqq
   ```
2. Simply open `index.html` in your browser:
   - On Windows: Double-click `index.html` or run:
     ```powershell
     start index.html
     ```
   - Or use VS Code / IDE Live Server extension.

---

## 🌐 Deployment

### GitHub Pages (Recommended)
1. Go to your repository on GitHub: `https://github.com/harishchimp1586-rgb/qqqq`
2. Navigate to **Settings** &rarr; **Pages**.
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**. Your site will be live at `https://harishchimp1586-rgb.github.io/qqqq/`.
